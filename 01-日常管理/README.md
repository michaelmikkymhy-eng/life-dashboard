# 01 · 日常管理

> 从 2026-08-08 起采用口述归档：你直接说每日情况，云端 AI 负责双写、校验和推送。

完整说明见根目录 [体系手册](../体系手册.md)。本目录是生活事实层，不是第二套手工账本。

## 目录

| 路径 | 内容 | 写入方式 |
|---|---|---|
| `日记/YYYY-MM-DD.md` | 每日作息、饮食、训练、消费、时间轴 | 仅云端 AI 通过 sync.py 写 |
| `数据/生活数据总台账.xlsx` | 每日记录、体成分、财务、库存、营养成分等唯一总台账 | 仅云端 AI 通过 sync.py 写 |
| `数据/sync.py` | 双写与一致性校验脚本 | 系统维护 |
| `数据/备份/` | 写入前快照与已知良好版本 | 脚本维护 |
| `财务/` | 财务 Markdown 视图与说明，不另建总账 | AI 整理 |
| `身材管理/` | 训练、体成分、维度 Markdown 视图与说明 | AI 整理 |
| `报告/周报/` | 第 34 周起 | AI 生成 |
| `报告/月报/` | 2026-07 起 | AI 生成 |
| `报告/年报/` | 年度汇总 | AI 生成 |

命令见 [命令速查](../99-系统/命令/命令速查.md)，规则见 [使用习惯与规范](../99-系统/规范/使用习惯与规范.md)。

## 使用方式

- **记录**：在手机或电脑 Trae 中直接说事实；AI 在云端同时写日记和 Excel，并运行当日 `check`
- **同步**：校验通过后立即 `git commit` + `git push`，本地 Obsidian 拉取 GitHub 镜像
- **不要**：在 Obsidian 手改日记或 Excel；手改会造成两边失配并被提交钩子拦截
