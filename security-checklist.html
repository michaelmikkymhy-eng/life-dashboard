安全加固清单

按顺序完成以下 3 步，你的生活台才能真正防止"开盒"

1
关闭开放注册紧急

问题：目前网站上有"注册新账号"按钮，任何人都能注册。如果你的数据库规则只检查"是否登录"，注册后就能看到你的所有数据。

操作步骤：

  1. 打开 Firebase 控制台
  2. 选择你的项目 my-life-dashboard-mhy
  3. 左侧菜单点 Authentication → Settings（设置）
  4. 找到 User Actions（用户操作）部分
  5. 找到 Enable create (sign-up)（启用注册）→ 关闭它
  6. 保存
做完这步后：别人就不能再注册新账号了。你已经注册的账号不受影响，仍然可以正常登录。
2
锁定数据库只允许你访问重要

问题：即使关闭注册，如果数据库规则写的是"任何登录用户都能读"，理论上如果有其他方式创建了账号，仍能读到数据。需要改成"只有你的账号能访问"。

第一步：找到你的用户 UID

  1. Firebase 控制台 → Authentication → Users
  2. 看到你的邮箱旁边有一串字母数字，那就是 User UID
  3. 复制这串 UID（类似 abc123XyZ456...）

第二步：修改数据库规则

  1. 左侧菜单点 Realtime Database
  2. 点 Rules（规则）标签
  3. 把规则改成下面这样（把 你的UID 换成你复制的 UID）：
{ "rules": { // 只有你的账号能读写 "users": { "你的UID": { ".read": "auth.uid === '你的UID'", ".write": "auth.uid === '你的UID'" }, // 其他用户什么都看不到 "$other": { ".read": false, ".write": false } }, // 其他路径全部禁止 "$other": { ".read": false, ".write": false } } }
  • 点 Publish（发布）按钮保存
    • 这步做完后：即使有人 somehow 创建了账号，也看不到你的任何数据。数据库被彻底锁死，只有你一个人能访问。
    3
    给 Google 账号加两步验证建议

    问题：你的 Firebase 项目绑定了你的 Google 账号。如果有人盗了你的 Google 账号，就能进 Firebase 后台看到一切。

    操作：

    1. 打开 Google 账号安全设置
    2. 找到 两步验证（2-Step Verification）
    3. 开启它（推荐用手机短信 + 验证器 App）
    这步做完后：即使有人知道你的 Google 密码，没有你的手机也登不进去。

    做完之后的防护等级

    能防住 99% 的"开盒"

    别人访问你的网址 → 只看到登录页，什么都看不到

    别人看网页源码 → 没有任何个人信息

    别人尝试注册 → 注册功能已关闭

    别人尝试读数据库 → 数据库规则锁死，只有你的 UID 能访问

    别人尝试盗你 Google → 两步验证挡住


    仍防不了的

    别人拿到你解锁的手机/电脑 → 能看到浏览器里的本地数据

    解决办法：手机设锁屏密码，不在公共电脑上登录

    完成以上 3 步后，你的生活台就具备了真正的防"开盒"能力
