# 生活档案

> 记录助手模式 · 从 2026-08-08 起，你直接告诉我每日情况，我负责归档。

**完整说明见根目录 [体系手册.md](../体系手册.md)**：数据怎么进、铁律是什么、换 AI 怎么接手，都在那里。本文件只做目录速查。

## 目录

| 路径 | 内容 |
|---|---|
| `日记/` | 每日生活日记（作息 / 饮食 / 训练 / 消费 / 时间轴），Markdown |
| `生活数据总台账.xlsx` | 结构化数据（每日记录 + 体成分 + 财务 + 库存 + 营养成分表 + 目标） |
| `周报/` | 第 34 周起 |
| `月报/` | 2026-07 起 |
| `成长/` | AI 学习与工具搭建文档 |
| `命令速查.md` | 写入命令 + 已验证事实 + 已知坑（新会话先读） |
| `使用习惯与规范.md` | 五条铁律、训练网格、分类归属细则 |
| `备份/` | 已知良好快照 |

## 使用方式

- **记录**：直接说今天的情况，AI 写成 `日记/YYYY-MM-DD.md` 并同步台账
- **查看**：问一句即可，或直接打开文件
- **不要**：手改 `日记/`，会造成 md 与台账不一致，提交被钩子拒绝
