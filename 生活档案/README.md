# 生活日记档案

> 记录助手模式 · 从 2026-08-08 起，你直接告诉我每日情况，我负责归档。

## 目录结构
| 路径 | 内容 |
|------|------|
| `日记/` | 每日生活日记（作息 / 饮食 / 消费 / 备注），Markdown 格式 |
| `生活数据总台账.xlsx` | 结构化数据（财务明细 + 每日记录 + 营养目标），Excel 表格 |

## 使用方式
- **记录**：直接跟我说今天的情况（吃了什么 / 睡了多久 / 花了多少），我会写进当天的 `日记/YYYY-MM-DD.md`，并更新台账表格。
- **查看**：随时问我一句，我立即汇报；或直接打开上述文件查看。
- **不需要**：再也不用打开网页、强刷缓存、部署。
