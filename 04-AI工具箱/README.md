# 04 · AI 工具箱

存放可迁移、可复用的 AI 工具，而不是某台电脑上的临时配置。

| 路径 | 用途 |
|---|---|
| `tools/` | 自研工具，每个工具独立一个子目录 |
| `skills/` | 自研 Skill，每个 Skill 自包含 |
| `prompts/` | 可复用提示词 |
| `进度.md` | 当前建设进度与验收状态 |

## 每个工具或 Skill 必须具备

1. **自包含**：代码、模板、示例和说明放在自己的目录内，不引用仓库外的私人路径。
2. **相对定位**：从 `__file__`、脚本所在目录或显式参数定位资源；禁止写死 `/workspace`、Windows 用户目录等绝对路径。
3. **依赖明确**：写清运行时版本、安装命令、配置项和最小验证方法。
4. **密钥外置**：API key、token、Cookie 等只从环境变量或仓库外配置读取；示例只写占位符，真实密钥不得入库。
5. **数据边界**：日常日记与 Excel 只能通过云端 `01-日常管理/数据/sync.py` 写入；其他工具默认只读，不得绕过一致性校验。
6. **迁移验收**：在一个新目录复制该工具，按说明安装依赖并完成最小运行，才算可迁移。

涉及生活数据的工具应把台账路径做成参数，默认从仓库根目录相对定位，而不是假定当前工作目录。
