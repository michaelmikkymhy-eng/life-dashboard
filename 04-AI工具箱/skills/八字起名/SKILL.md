# 八字起名（bazi-qiming）

## 一、本 skill 做什么、不做什么

**核心任务**：根据出生时间（公历年月日时分 + 性别 + 姓氏/偏好），先由脚本排出八字、定日主强弱与喜用神，再据此给出取名方案。默认支持三线并出：**大名**（命理补益为主，§四~§九）、**小名**（音义优先 + 五行软呼应，§十）、**英文名**（音近/义近/首字母三映射 + 文化避讳，§十一）。

**与其它 skill 的边界**：

| skill | 分工 | 本 skill 的边界 |
|-------|------|----------------|
| `bazi-mingli`（八字命理） | 排盘、强弱、格局、用神、大运流年、双流派断命 | **复用其排盘与喜用神结论**，不重复推导体系 |
| `na-yin-shi-ren`（纳音识人） | 纳音取象、性格/阶段 | 不涉纳音 |
| `liu-yao-divination`（六爻） | 断占问之事 | 完全独立，禁止互引 |

**不做什么**：不推大运流年、不断事业婚恋财富健康（那是 bazi-mingli 的落地层）、不算紫微/奇门、不把五格数理冒充命理结论。

---

## 二、铁律（贯穿全流程，违反即错）

1. **先喜用神、后补益（最核心）**：取名**绝不「缺什么补什么」**。正确顺序是：日主强弱 → 格局 → 用神（四法）→ 喜神/忌神 → **按喜神五行补**。反例（常见市面错误）：命局火旺水竭而身弱，若按「缺金缺土」去补金土＝错上加错；正确是**补水补木**（水制火润木救身、木帮身通根）。
2. **排盘只信脚本**：四柱、藏干、五行统计一律由 `bazi-mingli/paipan.py` 产出，禁止口算、禁止采信第三方排盘软件的「月空/时空/纳音」等非标准字段。
3. **命理层与文化层严格分离**：
   - **命理层**（八字补益：喜用神→补益五行→字根方向）有定式，可查可验；
   - **文化层**（音形义、出处、五格数理、生肖字根、风格）是审美/姓名学体系，与命理是**两套独立体系**，只并列出，禁止互相「背书」。
4. **不过度解读**：只能给「补益五行 → 候选字根/字」的**方向性结论**，禁止断言「取某字就一定大富大贵/改命」。每个名字的「五行补益」属命理定式，「能否改运」不承诺。
5. **边界声明**：起名无标准答案，最终以本人/父母对音形义的喜好为主，八字五行作参考；涉及改名、户籍登记等现实操作，附「仅供参考」声明。
6. **五格降级（默认不启用）**：五格三才属民俗姓名学，其「五行」由笔画尾数定（以数代五行），与 §4.1 干支五行是两套无关体系——**默认不计算、不输出**；仅在用户明确要求「姓名打分/数理吉凶」时作民俗参考给出，且结果**不参与、不否决八字补益结论**。

## 四、八字喜用神（复用 bazi-mingli 推导，按此四步）

> 本节结论与 `bazi-mingli` SKILL §5.1（强弱）+ §5.3（取用四法）完全一致，作为取名的唯一命理输入。

### 4.1 定日主强弱（五要素，权重递减）

1. **得令**：日主在月令是否当令（十二长生：长生/冠带/临官/帝旺＝得令；余＝失令）。
2. **得地**：四支藏干中日主同五行（比劫）或生扶（印）是否通根。
3. **得势**：四天干比肩/劫财有无并透。
4. **得生**：印星（生我之五行）在天干地支是否有力。
5. **得助**：比劫是否成势。

**判定**：得令 + 得地/得势 ≥2 项 → 身强；失令 + 无根 + 无帮扶 → 身弱；其余 → 中和。

### 4.2 取用神（四法定调，显式写明用哪一法）

1. **扶抑**：身强用克泄耗（官杀/食伤/财），身弱用生扶（印/比劫）。
2. **调候**：冬生寒用火暖局，夏生燥用水润局——调候为急，常优先。
3. **通关**：两神相战取通关之五行（官多用印、食伤克官用印制）。
4. **病药**：「病」（忌神旺/结构坏）→ 取去病之字为「药」。

**输出**：用神（扶起平衡的关键字）＋ 喜神（生用神者）＋ 忌神（克用神/坏格局者）＋ 闲神。

### 4.3 给取名层的最小交付

一行结论，例如：
> 乙木日主，失令于酉（七杀当令）、食伤火旺泄身、印癸水虚浮无根 → 身弱 → 扶抑+通关：**用神=水（制火、化杀、润木、生身），喜神=木（帮身通根），忌火、慎金**。

## 五、喜用神 → 取名方向（本 skill 核心）

### 5.1 补益方向

由 4.3 的「喜神/用神」定补益五行，由「忌神」定规避五行。

- **补益 = 用神 + 喜神** 的五行（用神为主、喜神为辅）。
- **规避 = 忌神** 的五行（及病药判断出的「药」之外的病五行）。
- 若身中和、无明显偏枯：以「调候 + 寓意美感」为主，补益放轻。

### 5.2 喜神五行 → 取名取向查表

| 喜神五行 | 补益 | 主要字根（部首） | 寓意取向 |
|---------|------|-----------------|---------|
| 木 | 补木 | 木、艹、禾、竹⺮ | 仁、生长、扎根、成材、文化、涵养 |
| 火 | 补火 | 火、灬、日、赤、光 | 礼、文明、表达、光明、热情、上进 |
| 土 | 补土 | 土、山、石、田、宀、玉(王) | 信、稳重、承载、平安、包容 |
| 金 | 补金 | 金、钅、刂、刀、戈 | 义、决断、坚刚、正直、成器 |
| 水 | 补水 | 氵、氺、冫、雨、水 | 智、流动、润泽、智慧、涵养、圆融 |

## 六、选字定式（字根 → 五行）

### 6.1 双通道判定（以字形部首为主，义属为辅）

1. **部首通道（主）**：按表 5.2 的字根（部首）直接归五行，无争议、可查可验。
2. **义属通道（辅）**：字义归五行（如「川」义为河流→水，「森」义为林木→木），用于部首不明确之字。
3. **争议字标注**：部首与义属、或不同姓名学对同一字五行有分歧时（如「辰」「宸」「然」），**必须标注「五行有争议」**，不作为主用字，或降为备选。

### 6.2 各五行常用字（部首明确，可直接取）

- **木**：柏、松、楠、桐、楷、梓、栩、森、林、栋、棠、槿、栎、榆、樾、柯、桥、柳、梅、桂、彬、楚、莘、荣、芙、萱、若、芷、蔚、苍、艾、芸、薇、蕾、秉、穗、笙、筠、箐。
- **火**：烨、炎、烁、煌、焕、煜、炜、曦、昀、旭、昕、晴、明、晨、晟、昊、昱、晶、昂、昭、丹。
- **土**：宇、安、宥、宁、坤、培、圭、岚、峰、峻、岩、磊、屿、城、均、坦、疆。
- **金**：铭、钰、锦、钧、锐、铠、锋、镇、鑫、钦、铎、铃、钊。
- **水**：泽、润、涵、沐、泓、渊、源、清、淳、沁、澈、潜、漾、涛、浩、滨、渝、潇、沅、洛、泷、浚、泳、津、澜、霖、霁、霈、霄、雪、云、泉、永、泰、淼、冰。

> 取字优先用部首明确、无争议、寓意正面、不算生僻的字；生僻字、多音字、易歧义字一律排除或标注。

## 七、音形义校验（文化层）

### 7.1 音（声）

- **声调**：避三连平/三连仄、避拗口；姓氏与名首字声调错落为佳。
- **谐音**：排查不雅谐音、歧义、易被起外号（如「其X→骑X」类）。
- **声母韵母**：避连续同声母或同韵母的拗口组合。

### 7.2 形（字）

- **笔画**：避过繁（难写难认）、过简（显单薄）、结构失衡。
- **结构**：上下/左右/独体搭配，姓名整体视觉协调。

### 7.3 义（意）

- **寓意**：正面、积极，避消极/不吉字义。
- **出处**：若从经典取材（诗经/楚辞/唐诗/宋词/周易/道德经等），必须标注「出自哪部、哪篇、原文哪句」；禁止杜撰出处。

## 八、五格三才（民俗参考层，默认不启用）

> 五格数理属**民俗姓名学五格派**，与八字命理是两套完全无关的体系：其「五行」由笔画尾数定（8.2 的 1–2 木…9–0 水），并非 §4.1 的干支五行，属「以数代五行」。它的笔画繁简参考已由 §7.2「形」校验覆盖。因此本 skill **默认不计算、不输出五格**。**保留本节仅为：用户或长辈明确在意「姓名打分/数理吉凶」时，提供一个民俗口径的交代。**

### 8.1 何时启用

仅当用户明确问「打分多少、数理吉不吉、五格好不好」时才计算并输出；否则一律跳过。

### 8.2 计算（启用时，康熙字典笔画）

- **天格** = 单姓笔画 + 1；**人格** = 姓 + 名首字；**地格** = 名首字 + 名末字（单字名 +1）；**外格** = 名末字 + 1；**总格** = 姓 + 名全部笔画。
- **三才**：三格尾数定五行 1–2 木、3–4 火、5–6 土、7–8 金、9–0 水，查相生。
- **数理**：参照通行「81 数理吉凶」判断总格/人格/地格，不逐条杜撰吉凶表。

### 8.3 启用时的两条硬声明（必写）

1. 标注「五格属独立民俗体系，与八字喜用神无关，仅供参考，不改变候选字的五行补益结论」。
2. 标注笔画标准（康熙字典为准），提示「不同字库存在 ±笔 差异」。

## 九、风格与禁忌（文化层）

### 9.1 风格清单

诗经楚辞风 / 古风雅韵 / 现代简约 / 自然意境 / 品德寓意 / 独特小众。

### 9.2 起名禁忌

- 忌生僻字（不会读、打不出）。
- 忌不雅谐音、易被起外号。
- 忌过大的字（「天」「帝」「皇」等，传统说怕压不住）。
- 忌与长辈（家族字辈/近亲）重字。
- 忌性别混淆（除非刻意中性）。
- 忌消极/不吉字义。

### 9.3 生肖字根（次要参考，次于八字）

以年支定生肖，查生肖喜忌字根（如属马喜「艹、禾、宀」、忌「子」）。**仅在八字补益已满足的前提下作微调**，八字喜用是主，生肖是民间参考，禁止因生肖否决八字补水的刚需。

## 十、小名（乳名）SOP

> 小名的使用场景是家人/亲密关系，核心是「好叫、顺口、亲昵」。**音义优先、五行软呼应**：不搞五格、不搞笔画吉凶、不强行塞生僻五行字。

**五套取法（优先级递减）**：

1. **大名派生**：从大名取一字或一音叠化（如大名「泽楷」→ 泽泽 / 楷楷 / 小泽）。
2. **五行意象**：用喜神五行自然意象轻声字——补水：淼淼/小雨/泉泉/润润；补木：森森/苗苗/芽芽/木木；补火：暖暖/明明/灿灿；补土：安安/磊磊/稳稳；补金：铮铮/铛铛。
3. **叠字/单字+缀**：安安、乐乐、朵朵、圆圆、宝宝、宁儿、小满。
4. **寓意词**：平安、福福、喜喜、悦悦、甜甜。
5. **生肖/情境**：属相（虎→小虎/阿虎）、出生时节（冬→冬冬、春→芽芽）。

**校验（必做）**：连叫不拗口；无负面谐音（蛋蛋/狗狗类）；尽量取喜神五行意象（软性，不硬凑）；给出「长大仍可用」稳健版作备选。
**避讳**：忌与大名同字同音混淆；忌方言歧义；以 1–2 音节为宜。

**输出**：读音 / 取法来源 / 五行意象 / 场景适配。分首推、备选、稳健版。

## 十一、英文名 SOP

> 英文名与中文名是两套名字，只求「呼应」不求对应；避讳以**目标语言使用者的观感**为准。

**先确认用途**：惯用名（上学/对外，自由）vs 护照/证件名（受拼音约束，日常名可另取）。

**三映射取法（按序尝试）**：

1. **音近**：读音接近中文名/某字音（琳/林/霖→Lynn·Lin；凯→Kai；安→Ann；娜→Nina；子/紫→Zoe·Zara；睿→Ray）。
2. **义近**：寓意对应（晨曦→Dawn；光明→Ray·Clara·Lucas；智慧→Sophia·Hugo；木/林→Willow·Sylvia·Asher；水→River·Marina；平安→Serena·Pax；喜悦→Joy·Felix）。
3. **首字母**：呼应该姓氏拼音或名首字首字母。禁止生硬「中文谐音硬贴」制怪拼写。

**协调与避讳（必检）**：

- 与姓氏连读顺口、不歧义；避免过时名（Gertrude/Mildred/Bertha/Clarence 等）；避 Karen（网络变义）、Adolf/Judas/Lucifer/Isis（禁忌）、Christian/Jesus（宗教敏感，视家庭背景）、性别错位。
- 发音以中文母语者口音为准：避 `th` 重音、过重 `r`、词尾辅音簇（-ts/-sts）。

**输出**：拼写 / 读音 / 含义 / 呼应谁的什么 / 避讳已检。分首推、备选。
