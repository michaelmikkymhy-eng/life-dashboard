# 四柱八字命理（子平派 × 段建业盲派 双流派对照）

## 一、本 skill 做什么、不做什么

**只做一件事**：根据出生时间（公历年月日时分 + 性别），用脚本排盘，产出命盘事实；然后以**子平派（格局派为主、旺衰派为辅）**与**段建业盲派（宾主/体用/做功/象法/虚实）**两条独立方法论各断一次，最后并排对照。

**与其它 skill 的边界**：

| skill | 分工 | 禁止 |
|-------|------|------|
| `bazi-mingli`（本 skill） | 看八字：格局、旺衰、大运流年、财官、双流派对照 | 禁止用纳音取象当独立结论 |
| `na-yin-shi-ren`（纳音识人） | 只做纳音取象、性格/阶段倾向 | 禁止交叉引用本 skill 的吉凶结论 |
| `liu-yao-divination`（六爻） | 只断占问之事 | 与本 skill 完全独立，禁止互相「补结论」 |

**不做什么**：不算紫微斗数、不排奇门、不推流月流日细则、不做神煞体系全景（神煞仅在象法层作参考标签）。

## 二、铁律（贯穿全流程，违反即错）

1. **排盘只信脚本**：四柱、藏干、十神、纳音、空亡、十二长生、冲合刑害、五行统计、大运、流年，一律由 `paipan.py` 产出。禁止口算、凭记忆、或采信第三方排盘软件的「月空/时空/纳音」等非标准字段。真太阳时仅在用户**明确提供出生经度**时启用；否则按北京时间。
2. **双流派严格隔离**：子平派、段建业盲派各自独立分析、独立成段；禁止拿一派的结论去「补」另一派；禁止强行归一、禁止拼故事调和分歧。冲突时如实并列。
3. **区分「命盘上的」与「推测的」**：命盘事实（干支、藏干、十神、纳音、空亡、格局名、做功关系、冲合刑害）属**定式**，可查可验；由此推到的性格/事业/婚恋/财富/健康结论属**推测**，必须标「推测」并写明推理层级。
4. **不过度解读**：任何从「命盘 A」直接跳到「结论 C」而中间缺命盘依据 B 的推断一律删除；推理层级原则上不超过 2 步。神煞、纳音不参与格局定性和吉凶定性，只作色彩标签。
5. **格局取用有定式**：子平取格以月令藏干透干为准，从格须同时满足严格条件；取用神显式列四法（扶抑/调候/通关/病药）并说明采用理由，禁止凭感觉。
6. **引用有限定**：子平引用限《子平真诠》《渊海子平》《滴天髓》预置摘录；盲派引用限段建业《命理纲要》《盲派命理》体系术语。禁止凭记忆杜撰古文原文。

## 三、输入与排盘

### 3.1 用户需提供

- 公历出生日期与时间（年、月、日、时、分）。
- 性别（男/女，定大运顺逆必需）。
- 可选：出生地经度（需真太阳时校正时提供）。

### 3.2 排盘命令

```bash
python paipan.py <年> <月> <日> <时> <分> <男|女> [--jing 经度] [--liunian 年份]
```

示例：`python paipan.py 1990 5 20 14 30 男 --liunian 2026`

输出 JSON 字段：公历/农历/生肖/性别/真太阳时、四柱（每柱：干支、纳音、藏干、天干十神、地支十神、空亡、十二长生）、日主五行、胎元/命宫/身宫（附列，见 3.3）、五行统计、地支关系（冲/合/害/破/刑/三合半合）、天干五合、大运列表（干支/虚岁/公历起运年）、指定流年。

### 3.3 排盘注意事项（必读）

- **真太阳时**：脚本 `--jing 经度` 把北京时间换算为「经度与该地真太阳时」的校正（东经 120° 基准，每差 1° 约 4 分钟）。**默认不校正**；用户没说经度就不动时间。
- **子时（23:00–24:00）**：存在「晚子时」流派争议（日柱是否归次日、时干是否用次日）。脚本默认以 **0 点为日界**、23:00 起入子时按当日排。遇到晚子时出生，输出时须在「排盘注意」栏标注此边界，不做流派偏向。
- **胎元/命宫/身宫**：脚本顺带输出，属**附参**。子平格局派、旺衰派与段建业盲派的宾主体用做功体系**均不以命宫/身宫为断事支点**；纳音取象归 `na-yin-shi-ren`，不在本 skill 展开。
- **节气边界**：月柱、年柱由脚本按节气自动切换，勿手动干预。

## 五、子平派体系（格局派为主 + 旺衰派为辅）

### 5.1 第一步：定强弱（旺衰派，作为后续取用神的前置）

判断日主强弱看五要素，**权重递减**：

1. **得令**：日主在月支（月令）是否当令。查 4.7 十二长生：长生/冠带/临官/帝旺＝得令；衰/病/死/墓/绝/胎/养＝失令。月令权重最大。
2. **得地**：四支藏干中，日主同五行（比劫）或生扶日主（印）是否通根（有气）。查脚本「五行统计」+ 4.5 藏干。
3. **得势**：四天干中比肩/劫财（同五行）有无并透。
4. **得生**：印星（生我之五行）在天干地支是否有力。
5. **得助**：比劫是否成势帮扶。

**判定口径**：
- 得令 + 得地/得势 ≥ 2 项 → **身强**；
- 失令 + 无根 + 无帮扶 → **身弱**；
- 其余 → **中和**（介于之间，取用神需更精细）。

> 示例（脚本验证过的样本：庚午 辛巳 乙酉 癸未，乙木日主）：月令巳中丙旺（伤官当令、非比印），乙木无得令；四支午巳酉未无木根、无水生乙（癸水坐未弱、无根），故**身弱**。

### 5.2 第二步：取格局（格局派，核心）

**取格原则（《子平真诠》月令取格）**：

1. 取月支（月令）**本气**十神为格；
2. 本气不透干时，看月令中气/余气有无透干者，取透干者为格；
3. 均无透，仍以本气定格。

**格局与月令藏干十神对照**：

| 月令本气（或透干）十神 | 格局名 |
|---|---|
| 正官 | 正官格 |
| 七杀 | 七杀格（偏官格） |
| 正财 | 正财格 |
| 偏财 | 偏财格 |
| 正印 | 正印格 |
| 偏印 | 偏印格（枭神格） |
| 食神 | 食神格 |
| 伤官 | 伤官格 |
| 比肩 | 建禄格（禄格） |
| 劫财 | 羊刃格（刃格） |

**特殊格局（从格/专旺/化气）**：

| 格局 | 成立条件（须同时满足） |
|------|----------------------|
| 从强格 | 印比独旺成势，局中无克泄耗（官杀/食伤/财）或极微弱 |
| 从财格 | 财星独旺成势，日主无根无助、无印比 |
| 从杀格 | 官杀独旺成势，日主无根、无印 |
| 从儿格 | 食伤独旺成势（我生极旺，从儿） |
| 专旺格 | 曲直（木）、炎上（火）、稼穑（土）、从革（金）、润下（水）：某五行成方成局独旺 |
| 化气格 | 日主与时干/月干五合且化神得令，化气成真 |

**从格警示**：从格须极严格（失令、无根、无印比、被选定之五行成势），差一点即回普通格局。宁取普通格，不轻断从格。

> 示例（同上乙酉日主，月令巳，本气丙＝伤官）→ **伤官格**。

### 5.3 第三步：取用神（四法定调）

在「格局 + 强弱」基础上定用神，显式写明用哪一法：

1. **扶抑**：身强用克泄耗（官杀/食伤/财），身弱用生扶（印/比劫）。
2. **调候**：冬生寒用火（暖局），夏生燥用水（润局）——调候为急，常优先。
3. **通关**：局中两神相战（如官多用印化、食伤克官用印制），取通关五行。
4. **病药**：命局之「病」（忌神旺、结构坏），取能去病之字为「药用神」。

**用神/喜神/忌神/闲神**：用神＝扶起命局平衡的关键字；生用神者＝喜神；克用神/坏格局者＝忌神；其余＝闲神。

### 5.4 第四步：大运流年

- **大运**：一组干支管 10 年，看其天干地支的十神对原局用忌神是助是抑。
- **流年**：一年干支叠加在大运上，看引发原局冲合刑害、动用什么神。
- **断法**：大运/流年走**用神、喜神**旺地且不被合绊/冲克 → 吉；走**忌神**旺地或冲坏用神 → 凶；**合冲刑害**引动原局结构 → 应具体事。

## 六、段建业盲派体系（宾主/体用/做功/象法/虚实）

> 盲派**不依赖旺衰平衡**，核心是「谁对谁做功，把财官拿过来」。

### 6.1 宾主（分内外）

| 位置 | 归属 | 代表 |
|------|------|------|
| 年柱 | 宾 | 祖上、外人、长辈、领导、单位 |
| 月柱 | 半宾半主（月干＝事业宫） | 父母、同辈、同事、朋友 |
| 日柱 | 主 | 日干＝我；日支＝配偶宫、内助、我之根 |
| 时柱 | 主 | 子女、下属、我之手、归宿 |

**核心**：宾位的东西（财、官、名）要被「主」拿到手（制/合/化），才是自己的。

### 6.2 体用（分工具与对象）

- **体**：日主及与「我」同气之字（比劫、日支、时柱等近我之位），即「我手里有什么工具」。
- **用**：宾位可被体作用的对象（财、官）。
- **要点**：体与用之间要发生「做功」，体去克/合/化/冲/穿用，得到的财官方为实。

### 6.3 做功（盲派核心，判富贵层次）

**做功 = 命局中一个（或一组）字对另一个字发生的实质作用**，方式如下：

| 做功方式 | 定义 | 取向 |
|---------|------|------|
| 制（克） | 用食伤制官杀、比劫制财、印化杀 | 制得有力＝掌权/得财 |
| 合 | 日主合财、合官（天干五合/地支六合/三合） | 合住为我用 |
| 化 | 合而化气成真（化神得令） | 化气改命 |
| 冲 | 冲开财库/官库、冲去忌神 | 开库得财官 |
| 刑 | 刑出/刑开（破而后立） | 灾中带得，多纠纷 |
| 穿（害） | 相穿，暗伤 | 多凶，主背后受害 |
| 墓（收） | 入墓、收库、闭库 | 得而藏，或囚禁 |
| 破 | 相破 | 主破坏、事难成 |

**判读三重**：

1. **找准做功的字**：通常是日主或体格的字，对宾位财官做功。
2. **看力度**：做功之字是否当令、通根、有力 → 富贵层次高低（真做功）还是花瓶（假做功）。
3. **看大运**：大运字是「帮做功」（加力、护主）还是「坏做功」（绊住、冲散、穿破）。

> 示例（庚午 辛巳 乙酉 癸未）：日主乙坐酉（杀），月时两辛金七杀并透攻身——此局是「杀重攻身」，需看印（癸水）能否化杀、食伤（巳中丙）能否制杀。盲派断点不在「身弱要扶」，而在「杀与食伤/印之间谁做功、能否制住杀」。

### 6.4 象法（四层读象，把字读成「话」）

按层级叠加，落到具体人事（每层必须有命盘依据，最多两层推理）：

1. **干支象**：十干本象（甲=大树/栋梁、乙=花草/藤、丙=太阳、丁=灯烛、戊=城墙、己=田园、庚=钢铁、辛=珠宝、壬=江河、癸=雨露）；十二支本象（子=鼠/水、丑=牛/库、寅=虎/木、卯=兔/花草、辰=龙/水库、巳=蛇/火、午=马/火、未=羊/木库、申=猴/金、酉=鸡/金、戌=狗/火库、亥=猪/水）。
2. **十神象**：正官=官职/约束/夫；七杀=威权/压力/凶；正财=妻/俸禄；偏财=父/经营财；正印=文凭/庇护/母；偏印=偏门学业；食神=才华/福气；伤官=锋芒/叛逆；比肩=同侪/合作；劫财=竞争/破财。
3. **宫位象**：见 4.4 宫位表。
4. **组合象**：干支组合、纳音、神煞叠加（仅作标签，不决定吉凶）。

### 6.5 虚实（看财官是否落地）

- **虚**：天干浮而无根（地支无同五行藏干）→ 有名无实、想法、抓不到。
- **实**：地支本气/藏干扎根 → 实在、落地、有形。
- **应用**：财官虚浮 → 虚名虚利、机会抓不住；财官坐实 → 真财真官。

### 6.6 盲派断命流程（固定顺序）

1. 排盘（脚本）。
2. 定宾主（年月为宾、日时为外→内）。
3. 分体用（我之字 vs 宾位财官）。
4. 找主做功对象（日用谁做什么）。
5. 定做功结构（制/合/化/冲/刑/穿/墓/破）。
6. 读象（四层象法落到具体、可验证的人事）。
7. 看大运（助功/坏功）。

## 七、双流派对照框架

对一个八字，两派各断完后再并列对照。

### 7.1 对照表

| 维度 | 子平派（格局+旺衰） | 段建业盲派 | 异同 |
|------|--------------------|------------|------|
| 日主强弱 | 身强/身弱/中和 | （不定强弱，看体用） | — |
| 核心结构 | 格局名（如伤官格） | 做功结构（制用/合化…） | 可能指向同一字 |
| 用/忌神 | 用神、忌神 | 做功之字 / 破功之字 | 对比是否同字 |
| 财官来源 | 财官星旺衰 + 宫位 | 谁做功得到的财官 | — |
| 大运喜忌 | 走用神运吉 | 走助功运吉 | — |
| 分歧点 | — | — | 如实列出 |

### 7.2 冲突处理原则

- 两派**一致** → 加强置信，可写「两派印证」。
- 两派**不一致** → 如实并列结论，**指出方法论根源**（子平看五行平衡与格局成败、盲派看做功与拿取），**禁止强行归一、禁止拼故事调和**。
- 归因示例：同样一个「杀重身弱」的盘，子平会说「身弱杀重，用印化杀通关」；盲派会说「杀重攻身，看有无制化之物，有则做功得权、无则受制」。两者关注点不同，结论可同可异，分别呈现即可。
