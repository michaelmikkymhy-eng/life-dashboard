# 纳音识人术（四象三垣胎息体系）

## 一、核心理念与适用范围

**本 skill 只做一件事**：以「四柱纳音 + 三垣纳音 + 胎息纳音」共八枚纳音点为依据，逐点取象，推演一个人的性格倾向与人生阶段走势。取象基准为《三命通会》纳音卷及盲派「三垣」传统。

与 `liu-yao-divination`（六爻解卦）是两套**相互独立**的方法论，各自断各自的事，禁止混用、禁止交叉引用、禁止拿六爻结论来「补」纳音结论，反之亦然。

**三条铁律**（贯穿全流程）：

1. **区分「定式」与「推测」**：纳音名称对应的自然/物象本义（如「泉中水」= 自地下涌出、清冽绵长之泉）属**定式**，可查可验；由此推到「聪明内敛、记忆力强」等人格/职业结论属**推测**，必须在输出中标注「推测」并写明推理层级。禁止把推测伪装成定式。
2. **只查表、不凭记忆**：胎元、命宫、身宫、胎息、纳音、五虎遁，每一步必须显式查表（引用表名 + 表内容），禁止「我记得」「应该是」。
3. **不过度解读**：纳音只说它的五行 + 本义象 + 阶段角色，不叠加性格画像、不测动机、不拼故事。任何「从象义 A 直接跳到结论 C」而中间缺纳音依据 B 的，一律删除。

## 二、输入与前置数据

**用户需提供**（缺一不可）：

- 四柱干支：年柱、月柱、日柱、时柱（如 甲申 丁卯 辛卯 己丑）。
- 出生时辰（时柱地支即为生时）。

**需派生的四柱之外数据**（本 skill 的核心计算）：

| 项目 | 作用 | 来源 |
|------|------|------|
| 胎元 | 先天受气、根基 | 月柱推 |
| 命宫 | 精神内核、性格倾向、早年 | 月柱 + 时柱推 |
| 身宫 | 后天努力方向、中年、身体 | 月柱 + 时柱推 |
| 胎息 | 先天神识显形 | 日柱推 |

四柱（4）+ 三垣（胎元/命宫/身宫 3）＋ 胎息（1）＝ **八枚纳音点**，构成「四象三垣胎息」八字级别识人框架。

## 四、派生柱推算（可复现步骤，逐步查表）

### 4.1 胎元（月柱推）

**口诀：月干进一位，月支进三位。**

1. 月柱天干顺推一位（天干序 甲乙丙丁戊己庚辛壬癸 循环）。
2. 月柱地支顺推三位（地支序 子丑寅卯辰巳午未申酉戌亥 循环）。
3. 组合得胎元干支，查第三节纳音表。

**逐位校验表**：

| 月干 | → 胎元干 | 月支 | → 胎元支 |
|------|----------|------|----------|
| 甲 | 乙 | 子 | 卯 |
| 乙 | 丙 | 丑 | 辰 |
| 丙 | 丁 | 寅 | 巳 |
| 丁 | 戊 | 卯 | 午 |
| … | 进一位 | … | 进三位 |

**验证示例（样本）**：丁卯月 → 丁进一 = 戊，卯进三（卯→辰→巳→午）= 午 → **戊午 = 天上火** ✓

### 4.2 命宫（月柱 + 时柱推）

**口诀：子起正月逆生月，安时顺数到卯。**

**步骤 1（定月宫）**：以「子」为正月，逆数到出生月（子→亥→戌→…），记下落位地支为「月宫」。

| 月序 | 正月 | 二月 | 三月 | 四月 | 五月 | 六月 | 七月 | 八月 | 九月 | 十月 | 十一月 | 十二月 |
|------|------|------|------|------|------|------|------|------|------|------|--------|--------|
| 月宫 | 子 | 亥 | 戌 | 酉 | 申 | 未 | 午 | 巳 | 辰 | 卯 | 寅 | 丑 |

**步骤 2（定时点）**：在「月宫」地支上放置**出生时支**；沿地支**顺时针**（子→丑→寅→…）逐位顺次下推时辰，一直数到「卯时」所在之位，该位地支即**命宫地支**。

**步骤 3（定天干）**：由年干用**五虎遁**（见第五节）数到命宫地支所在月位，得天干；与命宫地支组合，查纳音。

**验证示例（样本：卯月、丑时、甲年）**：
1. 卯月 = 二月 → 月宫 = 亥。
2. 亥上安丑时，顺数：亥=丑时、子=寅时、丑=卯时 → 数到卯时落于「丑」→ **命宫地支 = 丑**。
3. 甲年五虎遁：丑位 = 丁丑 → **命宫 = 丁丑 = 涧下水** ✓

### 4.3 身宫（月柱 + 时柱推）

**口诀：子起正月顺生月，安时逆数到酉。**

**步骤 1（定月宫）**：以「子」为正月，**顺数**到出生月（子→丑→寅→…），记下落位地支。

| 月序 | 正月 | 二月 | 三月 | 四月 | 五月 | 六月 | 七月 | 八月 | 九月 | 十月 | 十一月 | 十二月 |
|------|------|------|------|------|------|------|------|------|------|------|--------|--------|
| 月宫 | 子 | 丑 | 寅 | 卯 | 辰 | 巳 | 午 | 未 | 申 | 酉 | 戌 | 亥 |

**步骤 2（定时点）**：在「月宫」地支上放置**出生时支**；沿地支**逆时针**（子→亥→戌→…）逐位顺次下推时辰，一直数到「酉时」所在之位，该位地支即**身宫地支**。

**步骤 3（定天干）**：五虎遁定天干，组合查纳音。

**验证示例（样本：卯月、丑时、甲年）**：
1. 卯月 = 二月 → 月宫 = 丑。
2. 丑上安丑时，逆数：丑=丑时、子=寅时、亥=卯时、戌=辰时、酉=巳时、申=午时、未=未时、午=申时、巳=酉时 → 数到酉时落于「巳」→ **身宫地支 = 巳**。
3. 甲年五虎遁：巳位 = 己巳 → **身宫 = 己巳 = 大林木** ✓

### 4.4 胎息（日柱推）

**口诀：日干五合，日支六合。**

1. 日干查**天干五合**：甲己合、乙庚合、丙辛合、丁壬合、戊癸合。
2. 日支查**地支六合**：子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合。
3. 合出的天干 + 合出的地支组合，查纳音。

**验证示例（样本）**：辛卯日 → 辛与丙合（丙辛合）→ 胎息干 = 丙；卯与戌合（卯戌合）→ 胎息支 = 戌 → **胎息 = 丙戌 = 屋上土** ✓

### 4.5 派生柱校验清单（必做，逐项自检）

- [ ] 胎元：月干进一位、月支进三位，各对照 4.1 校验表。
- [ ] 命宫：月宫逆数表核对 → 顺数到卯核对 → 五虎遁天干核对 → 查纳音。
- [ ] 身宫：月宫顺数表核对 → 逆数到酉核对 → 五虎遁天干核对 → 查纳音。
- [ ] 胎息：五合、六合各查表核对 → 查纳音。
- [ ] 命宫/身宫天干必用五虎遁，禁止沿用日干或年干随口估算。
- [ ] 八枚纳音点全部显式标注「定式」（纳音五行 + 本义）来源。

## 六、四象分析框架（四柱纳音 → 人生阶段）

| 支柱 | 对应阶段 | 关注点（取象方向） |
|------|----------|--------------------|
| 年柱纳音 | 少年（祖业环境） | 出身底色、祖荫厚薄、先天资源 |
| 月柱纳音 | 青年（求学与人格形成） | 成长环境、性格养成、受教方式 |
| 日柱纳音 | 中年（婚姻事业） | 自身作为、配偶缘、事业承载 |

**四象生克互动（只做五行生克，不做人格联想）**：

- 年 ↔ 日：祖荫与自我（生克定「得助 / 需自立」方向）。
- 月 ↔ 时：成长环境与归宿（生克定「前后呼应 / 后劲不足」方向）。
- 生克仅取五行定式（如金生水、水克火），结论只到「哪一阶段助力/损耗哪一阶段」，不引申到具体事件。

## 七、三垣 + 胎息分析框架

| 项目 | 角色 | 取象方向 |
|------|------|----------|
| 胎元 | 先天根基 | 禀受天地之气的厚薄、体质底子、祖荫 |
| 命宫 | 精神内核 | 性格倾向、内在主星、早年运势 |
| 身宫 | 后天方向 | 努力方向、中年走向、身体/归宿 |
| 胎息 | 先天神识（原神） | 受胎之日的心念；**只对标时柱纳音**，看原神在现实的显形 |

### 7.1 三元连珠（胎元→命宫→身宫 顺次判定）

- 胎元、命宫、身宫三者纳音**顺次相生**（胎元生命宫、命宫生身宫）→ 「三元连珠」，主根、神、身气脉贯通，先天禀赋顺畅。
- 出现**相克** → 「三元不顺」，理智知路与本能不能自洽的「内核交战」（隐性冲突）。
- 例证（示范盘）：胎元天上火 → 命宫涧下水（火克水）→ 身宫大林木（水生木）＝「开局命克胎，三元不顺」。

### 7.2 胎息显形程度（只对标时柱，不参与上述判定）

**铁律**：胎息**不参与**四象顺生与三元连珠的内部判定；它只对标**时柱纳音**，看原神是否在现实中显形。

**判定步骤（可复现）**：

1. 取胎息纳音，判「原神成熟度」（纳音本义维度）：
   - **年轻象**：纳音本义为未成器 / 可塑 / 待成长（博主示例：白蜡金）→ 原神偏「年轻」。
   - **老成象**：纳音本义为已成器 / 沉稳 / 有定力（博主示例：屋上土）→ 原神偏「老成」。
2. 对标时柱纳音（时柱＝晚年 / 归宿 / 终点），结合象义契合度，评显形程度为**高 / 中 / 低**三档：
   - 原神**老成**、与时柱象义契合 → 显形度**高**。
   - 原神**年轻** → 本世成果多在为原神「成长赋能」，显形度**低**。

**校准说明（区分定式与主观）**：

- 示范盘（胎息屋上土 → 时柱霹雳火）博主判为「显形约 80%」，并自述「我个人的评判」——此为**主观打分**，非可复现算法，不纳入定式。
- 本 skill 只输出**高 / 中 / 低档位**，不承诺精确百分比（符合「日常不主动给精确数字」的项目铁律）。
- 博主仅给出白蜡金（年轻）、屋上土（老成）两个样例，完整分档表博主未提供；本 skill 按「纳音本义成熟度」归纳出三档参考表（见 7.3），**全程标注为推测性归纳、非博主原文、非古籍定式**，遇具体纳音仍以本义判据现判并标注「推测」。
- 显形度为纳音象义层面的定性，不延伸为「聪明 / 不聪明 / 成就高低」。

## 十一、流派差异与交叉校验注意事项

1. **命宫/身宫口令不唯一**：存在「紫微斗数（寅起正月）」与「八字三垣 / 盲派（子起正月）」两套体系，二者地支结果不同，纳音可不同。本 skill 采用**与参考博主输出一致的「子起正月 + 数到卯/酉」法**（已由国易堂、生肖网等载诀佐证，并在第十节样本通过验证）。若外部排盘软件给出的命/身宫与本 skill 不一致，以本 skill 查表为准并标注差异，不强行归一。
2. **胎息流派**：胎息推算存在多法，本 skill 采用「日干五合 + 日支六合」法（与样本一致），仅此一法，不混用。
3. **纳音五行 vs 正五行**：本 skill 只取**纳音五行**做生克与取象，不引入干支正五行（藏干、旺相休囚等），避免体系混杂。
4. **范围边界**：本 skill 给出的是「取象 + 阶段 + 五行生克」层面的识人结论，不做吉凶应期、不做量化（金额/年限）、不做人生重大事件的确定性断言。
