# 潮汕牛肉火锅常识库

> 更新时间：2026-07-31
> 用途：用户吃潮汕牛肉火锅时，根据部位估算营养

## 一、牛肉部位分类（按脂肪含量从低到高）

### 瘦肉型（脂肪低，~5%以下）

| 部位 | 位置 | 脂肪特点 | 口感 | 估算营养/100g |
|------|------|----------|------|--------------|
| **嫩肉** | 臀部/后腿 | 几乎纯瘦，脂肪极少 | 最普通，肉质嫩 | ~120kcal / 蛋白22g / 脂肪3g / 碳水1g |
| **三花趾** | 前腿腱子肉 | 瘦肉带筋，脂肪低 | 弹嫩，有嚼劲 | ~125kcal / 蛋白21g / 脂肪4g / 碳水1g |
| **五花趾** | 后腿腱子肉 | 瘦肉带筋，脂肪低，比三花趾更瘦 | 筋更多更弹 | ~120kcal / 蛋白22g / 脂肪3g / 碳水1g |
| **匙柄** | 肋骨下方 | 瘦肉为主，中间有细筋 | 柔嫩有弹性 | ~130kcal / 蛋白21g / 脂肪5g / 碳水1g |
| **匙仁** | 脖仁下方，连肋骨 | 瘦中带一点点油花 | 柔嫩，肉香 | ~140kcal / 蛋白20g / 脂肪6g / 碳水1g |

### 中等脂肪型（脂肪~10-15%）

| 部位 | 位置 | 脂肪特点 | 口感 | 估算营养/100g |
|------|------|----------|------|--------------|
| **吊龙** | 牛里脊/脊背 | 肥瘦均匀，2分油8分肉 | 软嫩，有油脂香 | ~180kcal / 蛋白18g / 脂肪12g / 碳水1g |
| **吊龙伴** | 吊龙侧边 | 比吊龙稍肥 | 更香更嫩 | ~200kcal / 蛋白17g / 脂肪15g / 碳水1g |

### 高脂肪型（脂肪~20-40%）

| 部位 | 位置 | 脂肪特点 | 口感 | 估算营养/100g |
|------|------|----------|------|--------------|
| **雪花/脖仁** | 颈部 | 大理石纹脂肪，肥瘦交织 | 肥嫩，入口即化 | ~250kcal / 蛋白15g / 脂肪20g / 碳水1g |
| **肥胼** | 腹部夹层肉 | 一层红肉一层厚脂肪 | 肥香，油味重 | ~300kcal / 蛋白13g / 脂肪26g / 碳水1g |
| **胸口朥** | 胸部 | 纯脂肪块（白色） | 爽脆，嚼劲十足，满口油香 | ~400kcal / 蛋白10g / 脂肪40g / 碳水0g |

## 四、关键提醒

1. **潮汕牛肉火锅不算"减脂杀手"** — 只要不吃肥胼/胸口朥/雪花，选瘦肉部位，蛋白质高脂肪可控
2. **炸腐皮是隐藏热量炸弹** — 2片30g约150kcal，减脂期少吃
3. **沙茶酱30g约105kcal** — 蘸酱容易被忽略，但热量很高
4. **锅底清汤几乎0热量** — 牛骨清汤不算热量，但喝多了钠高
5. **每盘肉55g是生重** — 涮熟后缩水约15%，约47g熟肉/盘
